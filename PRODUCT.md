## Users and purpose

MCPS students checking StudentVUE grades and exploring hypothetical assignment scores. The application makes grade information readable and recomputes hypothetical changes without changing school records.

## Capabilities and constraints

Existing buildless vanilla JavaScript ES modules, CSS, hash routing, and GitHub Pages deployment remain. Preserve the Cloudflare relay and all login/dashboard functionality. Landing demonstrations use explicitly labeled sample data and the application's grading functions. No real-account login tests during visual work.

Existing app routes include grades, course editing/optimizer, schedule, attendance, documents, settings, FAQ, privacy, and credits. Feature availability is not evidence of full GradeMelon parity.
